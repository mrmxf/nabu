Lessons are plain Markdown files in a folder tree — no coding required. The tree
follows the [Hugo](https://gohugo.io) content model, so the same files work with
either renderer.

A **slide is the atomic unit of display** — one screen a student sees. A lesson
is an ordered sequence of slides.

Press **Next** to learn the layout.
